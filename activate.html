权限码是什么

权限码有两种：15 位短码，或以下格式的长 token：

base64url(payload).base64url(ed25519_signature)

长 token 使用 Ed25519 签名，软件可在本地离线验签。短码需要联网兑换为长 token，随后在本地验签。两种码都绑定签发时提供的设备指纹，不需要登录账号。

怎么拿到

  1. 打开软件 → 右上角「开通会员」，能看到当前的时长档位
  2. 加微信 wxid_kvni9uk7qnlc12（9:00–22:00），提供会员界面显示的设备指纹，并告知需要的档位
  3. 按软件里显示的金额转账或赞赏，把截图发过去
  4. 收到权限码，通常十分钟内

怎么激活

  1. 打开软件，点右上角「开通会员」
  2. 把短码或长 token 粘贴到弹窗底部的输入框
  3. 点「激活」
  4. 查看激活结果与会员到期时间
短码兑换需要联网；长 token 可以离线激活。新版 macOS 支持短码；目前下载的 Windows 版本请使用长 token。请保持电脑时间准确。

续期

同一设备续购时，新套餐时长从现有未吊销授权的最晚到期时间继续累加；如果已过期，则从新码签发时开始计算。有效期从签发开始，收到新码后请及时激活。新版客户端普通激活到期更早的码时，会保留有效期更长的本地授权并提示；旧版请使用最新签发的长 token。

换电脑

权限码绑定设备指纹，拷到另一台机器无法激活。换机前把旧电脑上的微信记录导完，然后加微信 wxid_kvni9uk7qnlc12 说明情况，咨询换机。

重装系统

若重装后设备指纹未变，原授权仍在有效期内，可再次输入原码；指纹变化时请联系客服处理。
