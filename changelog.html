统一官网与客户端的新界面

  • 全新客户端壳层：首页、会话、导出、任务中心、会员、设置六个页面，统一视觉和状态语言。
  • 任务中心：总体进度、当前会话、成功/失败、警告和输出文件；记录保存在本机，重启后仍可查看。
  • 资源状态：已找到、未缓存、文件缺失、解密失败、格式暂不支持、部分完成。
  • 会员：短码与长 token 统一入口；激活失败不覆盖现有授权，较短授权不会覆盖更长授权。
  • 官网：新的信息架构、按系统分组的下载卡片、状态说明和路线图；移除外部字体依赖。
  • 语音转文字：TXT / JSON / XLSX 也会写入「【语音转文字】」，macOS 补齐 SILK 解码。
  • 朋友圈归档：新增「朋友圈」页，扫描本机 sns.db 并按作者导出 HTML 归档。
  • 缓存管理：设置页显示解密缓存占用，可一键清理，不影响密钥和已导出文件。
  • 加密 ZIP：导出时可设置密码，使用 AES 加密；HTML 会连同 media 一起打包。
  • 完整性报告：每次导出记录消息数、文件大小和 SHA256；超过 1.5 GB 自动分片并生成校验文件。
  • 隐私检查：导出结果可扫描手机号、身份证、银行卡和邮箱，只显示数量和掩码样本。
  • 联系人与批量账号：新增联系人搜索/标签/CSV 导出；首页支持批量导出全部账号。
  • 断点续传：中断或失败的导出任务可以在任务中心继续剩余会话。

会员与隐私更新

统一 Windows 与 macOS 的授权流程

  • 短码兑换：Windows 和 macOS 都支持 15 位短码联网兑换，也支持长 token 离线激活。
  • 续期保护：同一设备续购时累加有效期，激活较短授权时保留更长的现有授权。
  • 错误提示：区分格式、签名、设备、网络和证书错误，给出下一步处理方式。
  • 本地解密：读取微信 4.x 的 SQLCipher 数据库，macOS 通过微信副本与 hook 自动获取密钥；旧版微信或排障场景保留命令行抓取方式。
  • 七种导出格式：TXT、Markdown、JSON、CSV、Excel、HTML、PDF。
  • HTML 归档：图片、语音、表情、引用回复原样还原，自带搜索框。
  • 本地语音转文字：Windows 使用 whisper.cpp 模型，macOS 使用 SenseVoice 模型，不上传、不按次收费。
  • 多账号：自动扫描本机登录过的微信账号，显示昵称而非 wxid。
  • 离线权限 token：Ed25519 v2 签名，本机验签，绑定设备指纹。
  • 隐私加固：只监听 127.0.0.1、随机端口、一次性令牌；移除更新检查与遥测。
