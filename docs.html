系统要求

项目要求
操作系统Windows 10 1803+ / Windows 11；macOS 11 及以上（Apple 芯片，当前主要测试 macOS 12+）
微信微信 4.x 桌面版（Windows / macOS），且已在这台电脑上登录过
磁盘程序约 200 MB；语音模型可选，Windows 约 181 MiB，macOS 约 239 MB + 词表（约 245 MB）；导出体积取决于聊天量

下载与安装

macOS

  1. 从网盘下载 macOS Apple 芯片安装包，打开后把 ChatVault.app 拖进「应用程序」
  2. 首次打开会被 Gatekeeper 拦（提示「无法验证开发者」或「已损坏」），打开终端执行一次：
xattr -cr /Applications/ChatVault.app

也可以右键点 App → 选「打开」→ 再点「打开」，效果一样。安装包没有 Apple 开发者签名，这一步躲不掉。

Windows

  1. 解压网盘里的 Windows 包，双击 ChatVault.exe
  2. SmartScreen 提示「Windows 已保护你的电脑」→ 点「更多信息」→「仍要运行」
  3. 需要 WebView2 运行时，Win10 1803 以后一般自带

选择账号

打开软件后，首页会列出本机登录过的微信账号。显示的是昵称，不是 wxid_xxx 这种内部标识——有数据库密钥后会从 contact.db 读出真实昵称并缓存，还没有密钥时显示「微信账号 · 89bb」这样的中性名字。

获取数据库密钥

微信 4.x 的数据库是 SQLCipher 加密的，必须先拿到密钥才能解密。三种方式：

1. 自动获取（推荐，macOS）

  1. 选中账号，点「自动获取密钥」
  2. 工具会复制一份微信、注入本地 hook 并启动副本
  3. 在微信副本里完成手机确认或点击「进入微信」，校验通过后密钥会写进本机配置并开始解密
过程说明：微信 4.x 的 hardened runtime 不适合普通进程附加。工具会把 hook 命中结果临时写入本机容器，校验完成后清理；聊天内容和数据库密钥不会上传。

2. 命令行（旧版微信或排障）

sudo ./ChatVault.app/Contents/MacOS/ChatVault --capture-keys \
  --pid $(pgrep -f 'WeChat.app/Contents/MacOS/WeChat') \
  --out ~/cv-key.json

微信 4.x 优先使用上面的自动流程；这条命令保留给旧版微信和排障场景。

3. 导入已有密钥

如果之前用别的工具取过密钥，直接在面板里粘贴 hex 即可，不用重复抓。

切换数据来源

macOS 的 TCC 不允许一个 App 读另一个 App 的容器目录，所以「数据来源」有两个选项：

选项需要什么说明
自动读取微信目录（默认）「完全磁盘访问权限」系统设置 → 隐私与安全性 → 完全磁盘访问权限 → 勾上 ChatVault → 退出并重新打开
自定义目录不需要授权指向任意含 wxid_*/db_storage 的目录，例如从别的机器拷来的 xwechat_files

切换来源会清空已保存的数据库密钥（密钥按账号保存），需要重新获取或导入。

勾选会话导出

  1. 选中账号 → 密钥通过后进入会话列表
  2. 按人、按群勾选要导出的会话
  3. 选格式、选时间段
  4. 需要转写语音就打开「语音转文字」（会员功能）
  5. 点导出，进度条走完自动打开输出目录
李老师_聊天记录/
├── index.html          ← 选择 HTML 时生成
└── media/
    ├── voice_0041.mp3
    ├── img_0087.jpg
    └── avatar_li.jpg

上面是 HTML 导出的示意结构；选择 PDF 会另外生成 PDF，联系人信息 CSV 需要单独导出。

七种格式

格式适合说明
txt贴到别处纯文本，最通用
md写笔记、进知识库Markdown，可导入 Obsidian / Notion
json二次开发、分析结构化，含发送者、时间、类型
csv丢进表格一行一条，UTF-8 BOM 编码
xlsx做统计、给同事看Excel 工作簿
html发给别人看带搜索、图片、语音，最完整
pdf打印、存档由 HTML 排版后转；macOS 用系统 WebKit，Windows 需要 Edge 或 Chromium

免费版开放 TXT / CSV；Markdown、Excel、HTML、JSON、PDF 为会员格式。时间范围筛选当前版本可用。

语音转文字

语音在本机转写，不上传、不按次收费。Windows 使用 whisper.cpp，macOS 使用 SenseVoice。

  • 首次使用时下载模型：Windows 约 181 MiB，macOS 约 229 MiB；下载后可离线转写
  • 转写结果会写进 HTML / PDF 导出文件，语音气泡下面多一行文字
  • 免费版此开关不可用，会提示开通会员

任务中心与状态

每次导出都会在「任务中心」留下记录：总体进度、当前会话、成功/失败数量、警告和输出文件。任务记录保存在本机，重启客户端后仍然保留。

状态含义可以做什么
已完成所有会话成功打开文件或输出目录
部分完成有会话失败，或部分媒体缺失打开结果并查看警告
失败没有成功导出任何会话查看原因后重试
已取消用户停止了任务重新导出

资源状态分为：已找到、未缓存、文件缺失、解密失败、格式暂不支持、部分完成。客户端会按状态给出下一步操作，例如重新获取密钥、切换格式或继续导出文字内容。

加密 ZIP 与完整性报告

导出时填写「加密 ZIP」密码，会把结果打包成 AES 加密压缩包；HTML 会连同 media 目录一起打包。每次导出都会记录消息数、文件大小和 SHA256，任务中心可以直接查看。超过 1.5 GB 的压缩包会按字节分片，并在同目录生成 SHA256SUMS.txt。

批量账号导出

首页「批量导出全部账号」会按账号顺序导出所有有消息的会话。没有密钥的账号会跳过并记录原因；任务中心显示当前账号、当前会话和成功/失败数量。批量导出同样支持格式、输出目录和语音转文字。

联系人

「联系人」页搜索昵称、备注或 wxid，按标签筛选，并导出联系人 CSV。联系人来自解密后的 contact.db，不需要联网。

分享前隐私检查

任务中心的导出结果可以点「隐私检查」，扫描手机号、身份证、银行卡和邮箱，只显示数量和掩码样本。检查 TXT / HTML / CSV / JSON / Markdown；压缩包和 PDF 需要先解压或转换。

朋友圈归档

客户端「朋友圈」页会读取本机 sns.db，扫描作者和时间线，再按作者或全部导出为 HTML 归档。需要数据库密钥；首次扫描可能需要一些时间，扫描结果会缓存在本机。

缓存管理

设置页会显示解密缓存的目录和占用，可一键清理。清理只会删除解密后的临时数据库和语音识别结果，不会删除数据库密钥、配置或已导出的文件；下次打开需要重新解密。

权限码激活

  1. 点左侧「会员」
  2. 选时长，向客服提供设备指纹，付款后获取短码或长 token
  3. 把权限码粘进「激活」输入框，点「激活」

新版 Windows 和 macOS 都支持联网兑换 15 位短码，也支持长 token 离线激活。授权绑定设备指纹，续购时长从已有有效授权的到期时间继续累加。详见权限码与激活。

常见故障

提示「无法验证开发者」/「App 已损坏」

执行 xattr -cr /Applications/ChatVault.app。这是没有 Apple 开发者证书的正常现象。

扫不到微信账号

macOS：确认已给「完全磁盘访问权限」并重启过 App；或者改用「自定义目录」指向 xwechat_files。

图片显示成「[图片]」

老会话的图片用了不同的加密容器，缺图片密钥时只能显示占位。文字和语音不受影响。

导出 PDF 失败

macOS 使用系统 WebKit，一般不需要额外安装；Windows 需要 Microsoft Edge 或 Chromium，装一个再试，或改用 HTML 格式。

激活提示「权限码无效」

请按会员页中的具体提示核对权限码、设备指纹、电脑时间和网络；仍有问题时把提示发给客服。
