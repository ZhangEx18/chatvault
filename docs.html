项目要求

下载与安装

macOS

  1. 从网盘下载 ChatVault-0.1.2-macos-arm64.dmg，打开后把 ChatVault.app 拖进「应用程序」
  2. 首次打开会被 Gatekeeper 拦（提示「无法验证开发者」或「已损坏」），打开终端执行一次：
xattr -cr /Applications/ChatVault.app

也可以右键点 App → 选「打开」→ 再点「打开」，效果一样。安装包没有 Apple 开发者签名，这一步躲不掉。

Windows

  1. 解压网盘里的 Windows 包，双击 ChatVault.exe
  2. SmartScreen 提示「Windows 已保护你的电脑」→ 点「更多信息」→「仍要运行」
  3. 需要 WebView2 运行时，Win10 1803 以后一般自带

选择账号

打开软件后，首页会列出本机登录过的微信账号。显示的是昵称，不是 wxid_xxx 这种内部标识——有数据库密钥后会从 contact.db 读出真实昵称并缓存，还没有密钥时显示「微信账号 · 89bb」这样的中性名字。

获取数据库密钥

微信 4.x 的数据库是 SQLCipher 加密的，必须先拿到密钥才能解密。三种方式：

1. 自动获取（推荐，macOS）

  1. 选中账号 → 勾选「先重启微信」
  2. 点「自动获取密钥」，系统会弹管理员授权框，输入密码
  3. 工具会重启微信、在 CCKeyDerivationPBKDF 下断点抄下口令与 salt，校验通过后自动写进配置并开始解密
为什么必须输密码：微信是 hardened runtime 且没有 get-task-allow，普通用户身份附加进程一定失败。抓取只在本机内存里读一次，不落盘、不上传。

2. 命令行（适合排查）

sudo ./ChatVault.app/Contents/MacOS/ChatVault --capture-keys \
  --pid $(pgrep -f 'WeChat.app/Contents/MacOS/WeChat') \
  --out ~/cv-key.json

3. 导入已有密钥

如果之前用别的工具取过密钥，直接在面板里粘贴 hex 即可，不用重复抓。

切换数据来源

macOS 的 TCC 不允许一个 App 读另一个 App 的容器目录，所以「数据来源」有两个选项：

选项需要什么说明
自动读取微信目录（默认）「完全磁盘访问权限」系统设置 → 隐私与安全性 → 完全磁盘访问权限 → 勾上 ChatVault → 退出并重新打开
自定义目录不需要授权指向任意含 wxid_*/db_storage 的目录，例如从别的机器拷来的 xwechat_files

切换来源会清空已保存的数据库密钥（密钥按账号保存），需要重新获取或导入。

勾选会话导出

  1. 选中账号 → 密钥通过后进入会话列表
  2. 按人、按群勾选要导出的会话
  3. 选格式、选时间段（会员可自定范围）
  4. 需要转写语音就打开「语音转文字」（会员功能）
  5. 点导出，进度条走完自动打开输出目录

七种格式

格式适合说明
txt贴到别处纯文本，最通用
md写笔记、进知识库Markdown，可导入 Obsidian / Notion
json二次开发、分析结构化，含发送者、时间、类型

免费版开放 TXT / CSV；Markdown、Excel、HTML、JSON、PDF 为会员格式。

语音转文字

语音在本机转写，不上传、不按次收费。Windows 使用 whisper.cpp，macOS 使用 SenseVoice。

  • 首次使用时下载模型：Windows 约 181 MiB，macOS 约 229 MiB；下载后可离线转写
  • 转写结果会写进 HTML / PDF 导出文件，语音气泡下面多一行文字
  • 免费版此开关不可用，会提示开通会员

权限码激活

  1. 点右上角「开通会员」
  2. 选时长，向客服提供设备指纹，付款后获取短码或长 token
  3. 把权限码粘进弹窗底部的输入框，点「激活」

长 token 可离线激活；新版 macOS 支持联网兑换 15 位短码，目前下载的 Windows 版本请使用长 token。授权绑定设备指纹，续购时长从已有有效授权的到期时间继续累加。详见权限码与激活。

常见故障

提示「无法验证开发者」/「App 已损坏」

执行 xattr -cr /Applications/ChatVault.app。这是没有 Apple 开发者证书的正常现象。

扫不到微信账号

macOS：确认已给「完全磁盘访问权限」并重启过 App；或者改用「自定义目录」指向 xwechat_files。

图片显示成「[图片]」

老会话的图片用了不同的加密容器，缺图片密钥时只能显示占位。文字和语音不受影响。

导出 PDF 失败

macOS 使用系统 WebKit，一般不需要额外安装；Windows 需要 Microsoft Edge 或 Chromium，装一个再试，或改用 HTML 格式。

激活提示「权限码无效」

请按弹窗中的具体提示核对权限码、设备指纹、电脑时间和网络；仍有问题时把提示发给客服。
